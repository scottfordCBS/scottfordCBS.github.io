STR Investment Finder privacy policy

Effective October 4, 2026.

STR Investment Finder is a private tool with a single user, its owner Scott Ford. No one else signs in to it or provides data to it.

Google data it uses

With the owner's permission, it reads and updates one Google Sheet ("STR Investment Finder") and creates and updates analysis documents in one folder of the owner's Google Drive. It uses the Google Sheets and Google Drive APIs for that purpose only.

What it does not do

It does not sell, share, or transfer Google user data to anyone. It does not use Google user data for advertising or to train AI models. It does not access any other files in the owner's Drive for any other purpose.

Storage

The authorization token is stored as an encrypted secret in the owner's private GitHub repository and is used only by the tool's scheduled run. The owner can revoke access at any time at myaccount.google.com/permissions.

STR Investment Finder's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
